# 株式会社ゆめみ iOS エンジニアコードチェック課題 - フィードバック対応版

## 概要

本プロジェクトは株式会社ゆめみ（以下弊社）のiOSエンジニアコーディングチェック課題に対する、私の回答です。

一次回答は完了しましたが、残念ながら選考通過とはなりませんでした。しかし、その際にいただいた詳細で建設的なフィードバックは、私のスキルをさらに向上させるための貴重な機会だと考えております。

このリポジトリは、いただいたフィードバックを元にコードを改善していくための**公開プロジェクト**として運用します。フィードバックをGitHubのIssueとして細分化し、一つずつ修正していくプロセスを公開することで、私の継続的な学習と成長への姿勢を示したいと考えています。

---

## アプリ仕様

本アプリは GitHub のリポジトリーを検索するアプリです。

![動作イメージ](README_Images/app.gif)

### 環境

- IDE：基本最新の安定版（本概要更新時点では Xcode 15.2）
- Swift：基本最新の安定版（本概要更新時点では Swift 5.9）
- 開発ターゲット：基本最新の安定版（本概要更新時点では iOS 17.2）
- サードパーティーライブラリーの利用：オープンソースのものに限り制限しない

### 動作

1. 何かしらのキーワードを入力
2. GitHub API（`search/repositories`）でリポジトリーを検索し、結果一覧を概要（リポジトリ名）で表示
3. 特定の結果を選択したら、該当リポジトリの詳細（リポジトリ名、オーナーアイコン、プロジェクト言語、Star 数、Watcher 数、Fork 数、Issue 数）を表示

## フィードバックの進捗

課題としていただいたフィードバックは、GitHubの[Milestones](https://github.com/toniremi/ios-engineer-codecheck/milestone/2)にIssueとして整理しています。
進行中の改善点については、各Issueをご確認ください。
